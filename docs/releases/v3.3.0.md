# Wext Static Publisher v3.3.0

## Changes

- Store exported assets, ZIP archives, bulk downloads, and activity logs in a private database table for each WordPress site. New exports no longer write generated files to the WordPress filesystem.
- Generate ZIP archives without temporary files and stream authenticated downloads from database storage.
- Read Cloudflare deployment assets from database storage and stream SFTP uploads through a bounded callback reader.
- Remove PHP and database error-display overrides and the related setting, preserving the site's error reporting configuration.
- Import existing ZIP archives without extracting them to disk. Keep the original files as backups and show an administrator notice if an import needs to be retried.
- Update archive retention, diagnostics, SEO file checks, and uninstall cleanup for database storage.

## Upgrade notes

Existing settings and REST routes remain available. Legacy archive import requires ZipArchive; failed imports can be retried by reactivating the plugin. Verify imported archives before manually removing the original files.

Allow database capacity for exported assets and uncompressed ZIP copies: approximately 2.7 times the exported bytes per retained build, excluding metadata and logs. The default retention limit is five builds. ZIP64 is not supported; archives must remain below 4 GiB with no more than 65,535 entries.

Custom integrations that previously received filesystem paths now receive logical `wext-db/...` identifiers. Use `Export_Storage` to read the corresponding data.

## Validation

Tests passed on clean WordPress Playground installations with `WP_DEBUG=true`, including PHP 8.1 and 8.3 database and ZIP checks. Coverage includes a 20-URL export, archive retention and bulk downloads, legacy migration and retry, authenticated REST downloads, SFTP callback byte fidelity, diagnostics, and uninstall cleanup.

Plugin Check reported **0 errors and 79 warnings** against the extracted distribution. PHP parsing passed for 388 files. ZIP integrity and the absence of shell scripts and bundled translation packs were verified.

Playground tests used SQLite. Production MySQL/MariaDB and large-site performance were not tested. Cloudflare requests were mocked, and SFTP was tested locally; no live deployment was performed.

See the [review validation report](../../wordpress-org/review-fixes-3.3.0.md) and [Plugin Check results](../../wordpress-org/plugin-check-3.3.0.json) for details.
