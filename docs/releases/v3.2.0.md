# Wext Static Publisher v3.2.0

This release adds SmartCrawl SEO support and fixes SEO output settings that could turn themselves back on after saving.

## Added

- Automatically detect SmartCrawl SEO and display its installed version under **SEO > SEO Plugins**.
- Add separate output controls for page, post, custom post type, and archive metadata, plus JSON-LD Schema, XML sitemaps, and `robots.txt`.
- Preserve SmartCrawl titles, descriptions, canonical URLs, robots directives, Open Graph tags, Twitter cards, and JSON-LD in static exports. Internal URLs are rewritten to the public static domain.
- Adapt Schema `SearchAction` to static search, or remove it when static search is disabled.
- Export SmartCrawl's sitemap index and linked sitemap files. Convert its WordPress query-based XSL stylesheets into static files so sitemap styling works without WordPress.
- Include the detected SmartCrawl version and output settings in the export manifest.
- Add a persistent local WordPress Playground setup and automated SmartCrawl integration tests.

## Fixed

- Keep unchecked SEO output settings disabled when WordPress sanitizes saved settings more than once.
- Preserve JSON arrays when removing Schema search actions and safely encode script-sensitive characters in SmartCrawl JSON-LD.

## Packaging updates since v3.0.5

- Standardize the plugin name, installation directory, and translation domain as **Wext Static Publisher** / `wext-static-publisher`.
- Replace the bundled search library with an MIT-licensed browser search script.
- Add WordPress.org directory metadata and screenshots, and exclude the vendor build script from the installable ZIP.

## Validation

- WordPress Playground smoke test and SmartCrawl integration tests passed on PHP 8.1.
- A live WordPress export using SmartCrawl 3.16.4 verified custom titles, descriptions, social tags, valid JSON-LD, sitemaps, static XSL files, and custom `robots.txt` rules inside the generated ZIP.
- Browser checks confirmed automatic detection and that disabled SEO settings stay disabled after saving.
- ZIP contents and archive integrity were checked.

## Installation

Download **`wext-static-publisher.zip`** from this release and upload it through **Plugins > Add New Plugin > Upload Plugin**. Existing installations using the `wext-static-publisher` directory can update in place.

SmartCrawl must be active in WordPress to generate its SEO output. SmartCrawl services that require PHP or remote APIs do not run in the static package.
